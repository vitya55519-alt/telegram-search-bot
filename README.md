# Telegram Search Bot

Бот для поиска всех комментариев пользователя в группах и чатах Telegram по username, телефону или ID.

## 🚀 Возможности

- ✅ Поиск по username (@username)
- ✅ Поиск по номеру телефона (+79991234567)
- ✅ Поиск по User ID (123456789)
- ✅ Доступ к полной истории сообщений
- ✅ Поиск во всех доступных группах и чатах
- ✅ Красивое форматирование результатов
- ✅ Прямые ссылки на найденные сообщения

## 📋 Требования

- Python 3.8+
- Telegram аккаунт
- API ID и API Hash с https://my.telegram.org/apps
- Bot Token от @BotFather

## 🔧 Установка

### 1. Клонирование и установка зависимостей

```bash
cd telegram_search_bot
pip install -r requirements.txt
```

### 2. Получение API credentials

1. Перейдите на https://my.telegram.org/apps
2. Войдите в свой аккаунт
3. Создайте новое приложение
4. Скопируйте `api_id` и `api_hash`

### 3. Создание бота

1. Напишите @BotFather в Telegram
2. Отправьте команду `/newbot`
3. Следуйте инструкциям
4. Скопируйте полученный токен

### 4. Узнайте свой User ID

1. Напишите @userinfobot в Telegram
2. Скопируйте свой User ID

### 5. Настройка переменных окружения

Скопируйте `.env.example` в `.env`:

```bash
cp .env.example .env
```

Заполните `.env` файл:

```env
API_ID=12345678
API_HASH=abcdef1234567890abcdef1234567890
BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrsTUVwxyz
ADMIN_ID=987654321
```

## 🎯 Использование

### Локальный запуск

```bash
python bot.py
```

### ☁️ Деплой на Railway

Подробная инструкция по деплою на Railway находится в файле [DEPLOY.md](DEPLOY.md)

### Команды

В Telegram откройте своего бота и используйте команды:

**Основные команды:**
- `/start` - Начало работы с ботом
- `/help` - Справка по использованию

**Поиск:**
- `/search @username` - Поиск по username
- `/search +79991234567` - Поиск по телефону
- `/search 123456789` - Поиск по User ID
- `/find <запрос>` - Альтернативная команда поиска

### Примеры

```
/search @durov
/search +79991234567
/search 12345678
/find @username
```

## 📊 Что показывает бот

Для каждого найденного пользователя бот выдаёт:

- 👤 Имя и ID пользователя
- 📊 Общее количество найденных сообщений
- 💬 Количество чатов, где найдены сообщения
- 📢 Список чатов с:
  - Названием чата
  - Количеством сообщений
  - Превью сообщений (дата, текст)
  - Прямыми ссылками на сообщения

## ⚠️ Ограничения

1. **Доступность чатов**: Бот может искать только в тех чатах, которые доступны вашему аккаунту
2. **Приватные группы**: Для поиска в приватных группах бот должен быть их участником
3. **Производительность**: Поиск в больших группах может занять время
4. **API лимиты**: Telegram имеет ограничения на количество запросов

## 🔒 Безопасность

- Никогда не делитесь своими `API_ID`, `API_HASH` и `BOT_TOKEN`
- Храните `.env` файл в секрете
- Не коммитьте `.env` в Git (уже добавлен в `.gitignore`)
- Используйте бота только для легальных целей
